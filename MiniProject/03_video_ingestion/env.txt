Purpose
Turn supported YouTube links into timestamped transcript records.

Proposed environment
- Shared Python environment with a pinned youtube-transcript-api dependency after compatibility testing.
- An approved metadata adapter, with a YouTube Data API adapter as an optional choice.
- Fixtures containing usable captions, missing captions, and unavailable videos.

Planned configuration
- TRANSCRIPT_LANGUAGES=th,en
- INGEST_TIMEOUT_SECONDS=30
- JOB_MAX_ATTEMPTS=3
- ENABLE_TRANSCRIPTION_FALLBACK=false
- YOUTUBE_API_KEY= (optional, only if the chosen metadata adapter requires it).

Dependencies
02 schedules jobs and owns persistence. 04 consumes normalized transcript segments. Caption access depends on provider availability and video access restrictions.

Optional extension
Fresh speech-to-text requires a separate provider, permitted access to audio, cost controls, and an implementation decision. It is not supplied by youtube-transcript-api.

Current status
The transcript adapter and fallback transcription are not implemented.
