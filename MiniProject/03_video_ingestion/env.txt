Module: Video Ingestion - YouTube Knowledge

Recommended environment
- A supported Python release with a tested youtube-transcript-api dependency.
- A metadata adapter, optionally using the YouTube Data API if selected by the team.
- Persistent transcript storage through 02_api_backend and indexing through 04_rag_knowledge.
- Test fixtures for Thai/English captions, missing captions, invalid links, and provider errors.
- An optional speech-to-text adapter only after its input-access method and cost are agreed.

Required configuration
- TRANSCRIPT_LANGUAGES=th,en: preferred accessible caption languages.
- INGEST_TIMEOUT_SECONDS=30: timeout for an individual external fetch attempt.
- JOB_MAX_ATTEMPTS=3: retry policy owned by the backend job system.
- ENABLE_TRANSCRIPTION_FALLBACK=false: do not start paid/new transcription by default.
- YOUTUBE_API_KEY=: optional, required only by a selected metadata/discovery API adapter.

Important requirements
- Preserve segment text, language, start time, duration, and transcript provenance.
- Validate known YouTube URL patterns; do not fetch arbitrary user-supplied destinations.
- Keep raw caption text separate from application/agent instructions.
- Deduplicate by normalized video ID within the applicable ownership scope.
- Distinguish unavailable captions from temporary access failures.
- youtube-transcript-api retrieves captions; it does not perform fresh speech-to-text.
- This is a planned adapter; no live ingestion code has been implemented.
