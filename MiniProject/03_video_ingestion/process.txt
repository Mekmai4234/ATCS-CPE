03_video_ingestion - Process & Techniques

Architecture
- IngestionService: async orchestration under backend ownership and total deadline.
- SubprocessCaptions / fetch_worker: synchronous SDK in a killable process.
- YouTubeMetadata: bounded async oEmbed or optional Data API videos.list snippet lookup.
- normalize: strict validation, stable IDs, original timestamps and provenance.
- IngestionAdapters: 03-owned composition delegating index/delete/evidence/inventory to 04.
- API/jobs/persistence/dedup/version/retries belong to 02; index publication belongs to 04.

Input / output
- Actual contract: ingest(video_id: str, context: ExecutionContext) -> TranscriptResult.
- Result uses existing 02 metadata, language, source and Segment schemas.
- Segment: segment_id, text, start_seconds, duration_seconds; 02 assigns transcript version.
- This supersedes the old design proposing additional per-segment video/version fields.

Techniques
- Language priority before manual/generated priority; no implicit translation/fallback language.
- Hash normalized language/text/start/duration plus duplicate occurrence for stable unique IDs.
- Retain overlaps and original time; reject invalid/nonfinite intervals rather than guessing.
- Metadata failure is separate from caption failure; missing fields remain null.
- Bound child stdout, discard stderr and strip provider credentials from child environment.
- Monitor durable ownership; cancellation/deadline kills and reaps the subprocess.
- Drain stdout after kill before wait/reap, within a 2-second cleanup budget. If drainage
  stalls, close the asyncio process transport and allow at most 0.5 seconds for final reap.
- Shield cleanup from repeated cancellation. Service close cancels and joins active fetches
  before any further cleanup, preventing concurrent reads from the same stdout pipe.
- 02 owns retries. Distinguish access blocks/no captions from transient service failures.
- Errors/logs omit raw provider messages, keys, transcript text and arbitrary URLs.

Scope / verification
- Reuse 02 watch/youtu.be URL support and deduplication.
- No changes to other modules' source or existing factories.
- Test actual SDK HTTP parsing with mocked HTTP and actual subprocess cancellation.
- Integration: real 02 API/worker/migrations, real 04 Chroma and fixture embeddings.
- Separate live public-caption check; observed results are in TEST_REPORT.md.
- FOLLOWUP_REPORT.md records the cleanup regression and real Thai/English acceptance checks.
- scripts/acceptance_check.py uses a new isolated DB/index and explicit fixture embeddings
  to check live captions, all stored timestamps, ready status and duplicate URL reuse.
- Root documentation may still describe the older planned-only status.
- Discovery/refresh/scheduling/authenticated access/ASR/container deployment remain separate work.
