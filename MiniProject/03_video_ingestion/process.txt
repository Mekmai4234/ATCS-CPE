Input
A normalized import job containing video_id, original_url, and the authorized data scope.

Flow
Validate provider -> retrieve metadata -> select accessible captions -> normalize segments -> persist transcript -> hand off to 04.
Skip unchanged transcript versions when already indexed.
Record per-video outcomes independently so one failed video does not block a batch.

Output
Video metadata and transcript segments with:
video_id, segment_id, text, start_seconds, duration_seconds, language, and transcript_version.
Preserve the canonical URL and transcript source.

Failure handling
No accessible captions -> no_transcript.
Temporary network/provider error -> retry according to the job policy, then failed if exhausted.
Unavailable or restricted video -> failed with a specific reason.
Optional transcription must never start silently when the fallback is disabled.

Limitations
This module reads spoken/caption text. It does not infer silent cooking actions, gameplay movement, or code shown only on screen.
