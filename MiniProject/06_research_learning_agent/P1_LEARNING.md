# P1 evidence reuse and learning quality

Explicit times are parsed using the existing shared `VideoPlan` before lookup or
fallback. Stored and newly returned native citations must stay wholly inside that
same window; overlap alone is insufficient. Invalid ranges fail before inference.
The full-team native integration supplies the ingestion planner; test-only source
paths and the Docker test allowlist use that same implementation without modifying 03
or adding a production dependency. Valid clock tokens constrain time rather than
lexical relevance; generation still receives the original topic.

Visual learning first checks the new 04 evidence library for private, current,
relevant native observations. Lexical overlap of at least 0.5 selects candidates;
it is not proof of semantic support. No hit falls back to the existing bounded native
video path. Older 04 releases keep that existing path without a missing-method failure.
No changes to 01/03/05 are required. Install the separate 04 PR to enable reuse.

Selected records are resolved again through 02's authorized VideoEvidenceStore.
Generation receives whole observation texts, observation kind, original interval and
canonical evidence ID, including qualifications/negation/replay warnings. Input budgeting
selects whole records and discloses partial selection. It never truncates factual text
to a display title. Final output rechecks ownership, source versions and exact stored
citations. The original shared member permit and backend quota broker remain mandatory.

Generation instructions adapt difficulty without adding facts, ask for fewer distinct
questions when evidence is limited, and prohibit paraphrased duplicates. Deterministic
validation rejects duplicate quiz prompts/card fronts after Unicode, punctuation and
case normalization. This check does not detect all semantic duplicates or prove that
an answer follows from its citations. Human review remains required. Repeated study
topics on different days remain permitted.

Only native `video` citations are consumed by the existing artifact contract here.
OCR/visual v2 evidence remains separately typed in 04; public v2 learning is not silently
enabled. Module 07 supplies a separately authorized, capped live probe for quiz,
flashcards and study plans, including durable publication and history reread. Its
contract results and manual educational-quality results must be reported separately.
