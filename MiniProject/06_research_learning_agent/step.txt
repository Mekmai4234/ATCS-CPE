### 06_research_learning_agent - Workflow Steps

A) Multi-step Research (implemented)
1. 02 persists a job and invokes research(request, sources, execution_context).
2. Validate the request and distinct authorized sources; read real index inventory from 04.
3. Check remaining job/run time, reserve, context guard and decision iteration budget.
4. Ask Gemini for one native function call with allowed tool declarations.
5. Preserve native content/signatures; validate the tool name and strict argument schema.
6. Execute search/read through 04, optional comparison through 05, or artifact generation.
7. Persist a concise action/outcome event through context.event; return the observation.
8. Let the next decision depend on that observation; credit evidence actually submitted.
9. Stop duplicate actions and enforce limits. On finish, validate known citation IDs and coverage.
10. Re-read exported citations and inventory; reject changed/missing sources before delivery.
11. Return completed only with complete coverage, otherwise partial, and emit a terminal
    run_controller event using the current step after validation.
12. 02 revalidates current sources/citations/inventory and durably stores the result/artifacts.

B) Direct Learning Artifacts (implemented)
1. 02 invokes artifact(request, sources, execution_context); no decision loop is required.
2. Enumerate authorized chunks from 04 in bounded pages; detect nonprogressing cursors.
3. Reject input that exceeds the explicit context guard instead of silently truncating it.
4. Generate a study plan, quiz with explanations, or flashcard set using the type's JSON schema.
5. Check item citation IDs against the actual supplied evidence, and exact requested plan days.
6. Count processed evidence after valid generation and return ArtifactResult for 02 to persist.

C) Failures and Delivery
- Every awaited model/tool call has a timeout bounded by remaining run time minus reserve.
- Cancellation/lost leases/source invalidation propagate and prevent publication.
- Step/context/time exhaustion returns honest partial research before the hard deadline.
- Partial findings preserve source excerpts and already validated artifacts, with coverage notes.
- Direct artifact generation with inadequate evidence/invalid output returns a classified error.
- Missing 05 is an explicit observation, allowing the agent to choose another supported action.
- SDK transport/provider errors are redacted; no raw messages, credentials or private reasoning.
- No automatic research replay/checkpoint resume is implemented.
