Module: Research & Learning Agent - YouTube Knowledge

Recommended environment
- A supported Python release and the Google GenAI SDK (google-genai).
- A bounded tool-calling loop with validated input/output schemas.
- Optional orchestration framework after the team evaluates whether it is needed.
- Persistent research-run state and progress records through 02_api_backend.
- Tools backed by 04_rag_knowledge and 05_ai_answers_analysis.

Required configuration
- GEMINI_API_KEY=: server-side Gemini credential.
- LLM_MODEL=gemini-3.5-flash: shared requested generation/tool-calling model.
- MAX_CONTEXT_TOKENS=24000: shared application context budget.
- AGENT_MAX_STEPS=8: maximum agent decision iterations.
- AGENT_TIMEOUT_SECONDS=120: total research-run deadline.
- AGENT_MAX_OUTPUT_TOKENS=2400: output limit per agent model response.
- LLM_TIMEOUT_SECONDS=60: upper bound per call, further limited by remaining run time.

Important requirements
- Carry authorized video scope through every tool call.
- Validate function arguments and reject unsupported tool names.
- Enforce step/deadline limits and preserve partial findings on budget exhaustion.
- Log concise operational events and tool decisions; do not require private model reasoning.
- Study plans, quizzes, and flashcards must reference supporting transcript content.
- Use the shared Gemini compatibility note in 05/env.txt; do not assume a requested alias
  always identifies the actual model serving a request.
- This is a design specification; no autonomous research loop is implemented yet.
