Module: Research & Learning Agent - YouTube Knowledge

Implemented environment
- Python >=3.11,<3.14; package: youtube_agent, installed using this module's uv.lock.
- Official google-genai SDK with explicit async HTTPX transport and native function calls.
- Local dependencies on 02_api_backend and 04_rag_knowledge; their files are not modified.
- Pydantic schemas reuse 02's research/artifact/source/citation contracts.
- Test environment: pytest, pytest-asyncio, Ruff, real temporary SQLite and Chroma.
- Isolated Linux Docker verification image; no network or credentials at test runtime.

Configuration (process environment > 06/.env > MiniProject/.env > defaults)
- GEMINI_API_KEY=: server-side key, required only for live generation.
- LLM_MODEL=gemini-3.5-flash: configurable requested model; verify live account access.
- MAX_CONTEXT_TOKENS=24000: application input budget.
- AGENT_MAX_STEPS=8: model decision iterations, including the final control call.
- AGENT_TIMEOUT_SECONDS=120: maximum total run time, bounded by the backend deadline.
- AGENT_FINALIZE_RESERVE_SECONDS=10: reserve for partial output/backend validation.
- AGENT_MAX_OUTPUT_TOKENS=2400: per-model-response output cap.
- LLM_TIMEOUT_SECONDS=60: per-operation ceiling, bounded by remaining run time.
- AGENT_READ_PAGE_SIZE=30: direct artifact chunk enumeration page size.

Boundaries
- 02 owns durable runs/events/artifacts and cancellation, 04 owns retrieval/indexing.
- 05 comparison is injected as an async analyzer; unavailable is explicit until connected.
- Source/version authorization uses 04 BackendExecution and 02's current job context.
- No model retries inside 06. The existing backend owns job-level retry policy.
- Model metadata records requested/returned identifiers, usage and measured latency.
- The 06 adapter factory consumes resolved backend Settings for agent/RAG configuration;
  standalone AgentSettings retains the module-local env precedence above.
- Native contents/signatures stay in memory; private reasoning is not persisted in events.
