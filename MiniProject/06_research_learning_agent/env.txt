Purpose
Orchestrate multi-step research and create grounded learning artifacts.

Proposed environment
- Shared Python environment and a model supporting validated tool calls.
- A bounded agent loop; an orchestration framework is optional and not selected yet.
- Persistent research-run records owned by 02_api_backend.

Planned configuration
- LLM_MODEL= (set after model/tool compatibility testing).
- AGENT_MAX_STEPS=8
- AGENT_TIMEOUT_SECONDS=120
- AGENT_MAX_OUTPUT_TOKENS=2400

Dependencies
Use authorized tools backed by 04 and 05: search_evidence, read_video_chunks, compare_videos, and create_learning_artifact.
Learning artifacts include study plans, quizzes, and flashcards. These tools may also support direct user actions without invoking the agent loop.

Current status
The orchestrator and artifact generators have not been implemented.
