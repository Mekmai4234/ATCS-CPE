### 06_research_learning_agent - Process & Techniques

Overview
Research orchestration and learning-artifact generation over imported transcript evidence.
Implemented as the Python package youtube_agent, called by 02's existing worker.
Live Gemini transport is implemented; executed validation uses offline fixtures/HTTP mocks.

Architecture
- AgentSettings: bounded configurable run/model/context settings, module-local env override.
- AgentService: per-run state, observation-driven decisions, coverage, artifact validation.
- GeminiModel: official SDK native function calls and schema-constrained artifact output.
- RagKnowledge: bridge to 04 using BackendExecution authorization/version checks.
- AgentAdapters: optional 06-owned composition for 02; 03/05 remain explicitly unavailable.
- Existing 02 schemas and execution context define persistence and integration boundaries.

Tools and Data
- search_evidence(query, top_k): ranked scoped retrieval from 04.
- read_video_chunks(video_ids, cursor, limit): authorized paginated transcript evidence.
- compare_videos(video_ids, instruction): optional injected 05 analyzer with citation checks.
- create_learning_artifact(type, topic): reuses direct artifact generation.
- finish_research(content, citation_ids): control function for the final validated result.
- Tool arguments cannot supply ownership, arbitrary URLs or replacement source generations.

Input/Output
- research(request, sources, context) -> 02 ResearchResult (completed or partial).
- artifact(request, sources, context) -> 02 ArtifactResult.
- Progress events: step, tool_name, state, summary; 02 attaches run ID/time.
- Result fields: content, citations, coverage, provider_metadata; research also has artifacts/state.
- Coverage uses distinct processed chunk IDs and 04 inventory, with explicit incomplete notes.
- Quiz/flashcards/study_plan content matches 02's strict schemas and item citation references.

Techniques and Limits
- Preserve function IDs and native model signatures for the next model call.
- Validate one declared function per decision; disable SDK automatic tools and SDK retries.
- Bound steps, total deadline and each await; reserve time for finalization.
- Count a retrieved observation after a successful subsequent decision, or valid artifact generation.
- Validate citation identity and source intervals; semantic support still requires evaluation.
- Ignore transcript instructions as authorization; operational events exclude private reasoning.
- Detect repeated actions, missing evidence and pagination that makes no progress.
- Use a local UTF-8 byte guard. Live preflight counts native contents with countTokens and
  adds a conservative config-byte allowance; it is not an exact count of all server-side framing.
- Direct artifacts currently need one bounded evidence input; large corpora fail explicitly.
- Partial research preserves excerpts/artifacts; hard timeout can still be failed by 02.

Verification and Operations

No other module's source, global Compose, shared env template or database migrations are changed.
