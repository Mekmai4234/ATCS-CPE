# ขอบเขตโครงการ

## ปัญหาและกลุ่มผู้ใช้

ผู้เรียน ผู้ค้นคว้า และคนที่สะสมคลิปไว้จำนวนมากมักเสียเวลาค้นหาประเด็นเดิม ระบบนี้ช่วยค้นจากคำพูดในวิดีโอ รวบรวมคำตอบ และเปิดกลับไปดูหลักฐานได้ เหมาะกับคลิปอธิบาย เช่น เทคโนโลยี ทำอาหาร หรือสอนเล่นเกม

## เป้าหมายส่งมอบเป็นระยะ

### ระยะ 1: ระบบหลักที่สาธิตได้
- วางลิงก์เดี่ยวหรือหลายลิงก์ ตรวจลิงก์ซ้ำ และแสดงสถานะแยกคลิป
- ดึงบทถอดเสียงที่เข้าถึงได้ พร้อมเวลา
- จัดทำฐานความรู้และถามตอบเฉพาะวิดีโอที่เลือก
- แสดงอ้างอิงพร้อมเวลา และแจ้งเมื่อไม่มีหลักฐาน
- ดูคลิปผ่านตัวเล่นที่ฝังได้ หรือเปิดต้นทาง

### ระยะ 2: วิเคราะห์และเรียนรู้
- สรุปและเปรียบเทียบหลายคลิปโดยตรวจความครอบคลุม
- ตัวกรองช่อง วันที่ และเพลย์ลิสต์เมื่อมีข้อมูลรองรับ
- ประวัติแชต แบบทดสอบพร้อมเฉลย และแฟลชการ์ด
- นำเข้าจากช่อง/เพลย์ลิสต์โดยมี pagination และจำกัดจำนวน
- ตรวจวิดีโอใหม่ด้วยคำสั่ง refresh

### ระยะ 3: Agent และการใช้งานต่อเนื่อง
- Agent วางแผน เลือกเครื่องมือ และค้นเพิ่มตามข้อมูลระหว่างทาง
- จัดแผนเรียนพร้อมหลักฐานและติดตามสถานะการค้นคว้า
- อัปเดตช่องตามกำหนด เมื่อเพิ่ม scheduler แล้ว
- ถอดเสียงใหม่เป็นส่วนเสริม เมื่อเลือกบริการและวิธีเข้าถึงเสียงที่เหมาะสม
- สมาชิกและสิทธิ์ข้อมูล หากต้องรองรับหลายผู้ใช้

## เกณฑ์สาธิตขั้นต่ำ

นำเข้าคลิปที่มีบทถอดเสียงจนพร้อมถามตอบ ถามคำถามที่มีหลักฐาน และกดกลับไปยังเวลาที่อ้างอิงได้
ทดสอบอีกอย่างน้อยหนึ่งคำถามที่ไม่มีข้อมูล คลิปที่ไม่มีคำบรรยาย และลิงก์ซ้ำ
ส่วน Agent ต้องแสดงการเลือกเครื่องมือจากผลลัพธ์ระหว่างทาง และหยุดได้เมื่อถึงขีดจำกัด

## ข้อจำกัดและสิ่งที่อยู่นอกขอบเขตเริ่มต้น

ไม่รับประกันว่าจะดึงคำบรรยายได้ทุกคลิป ไม่วิเคราะห์ภาพ/เสียงที่ไม่มีในบทถอดเสียงในรุ่นแรก
ไม่ให้คำมั่นเรื่องเวลานำเข้าหรือความแม่นยำก่อนมีผลวัดจริง
ไม่ยืนยันว่าคำพูดในคลิปเป็นข้อเท็จจริงเสมอ และต้องเก็บวันที่/เวอร์ชันเมื่อเกี่ยวข้องกับเนื้อหาที่เปลี่ยนตามเวลา
