Module: AI Answers & Analysis - YouTube Knowledge

Implemented environment
- Python >=3.11,<3.14; installable youtube_answers package.
- Google GenAI SDK (google-genai), Pydantic schemas and pydantic-settings.
- Local dependencies: 02 backend contracts and 04 versioned RAG evidence.
- Optional team extra adds 03 ingestion and 06 research/artifacts.
- pyproject.toml and uv.lock define the reproducible environment.
- See README.md for installation, commands, integration and operational limits.

Configuration
- GEMINI_API_KEY=: server-side credential; offline tests need no key.
- LLM_MODEL=gemini-3.5-flash: configurable project-requested identifier.
- LLM_TIMEOUT_SECONDS=60: per-operation ceiling within the backend deadline.
- MAX_CONTEXT_TOKENS=24000: application input budget, not model capacity.
- ANSWER_MAX_OUTPUT_TOKENS=1200: output ceiling per generation.
- ENABLE_STREAMING=false: true is rejected until validated streaming is implemented.
- RETRIEVAL_TOP_K=8: ranked question-answer retrieval limit.
- ANSWER_READ_PAGE_SIZE=100: whole-video enumeration page size.
- ANSWER_MAX_CHUNKS=5000 and ANSWER_MAX_MODEL_CALLS=64: explicit work limits.
- ANSWER_MAX_HISTORY_MESSAGES=12 and ANSWER_MAX_HISTORY_BYTES=4000: recent history limits.
- .env.example includes separate Gemini embedding and isolated live database settings.

Configuration precedence
- Standalone answers: process > 05/.env > MiniProject/.env > defaults.
- Optional full team: process > 05/.env > 06/.env > 03/.env > 04/.env > root .env.
- Backend Settings uses its existing loading rules; export adapter/profile/database
  variables explicitly in both API and worker terminals as described in README.md.

Model compatibility
- Model names and account access must be checked before live use. A configured name
  does not establish availability or alias routing; no live calls were made in offline tests.
- Store requested and returned model/version metadata, usage totals and call latency.
- Embedding configuration remains separate from generation configuration.
- SDK reference: https://googleapis.github.io/python-genai/

Verification
- Offline tests cover services, real SDK HTTP mocks and 02/04/06 integration.
- fixtures/evaluation.json contains synthetic manual-review cases.
- scripts/live_check.py requires --live before paid generation requests are allowed.
- TEST_REPORT.md records executed checks and limitations, not a claim of AI accuracy.
