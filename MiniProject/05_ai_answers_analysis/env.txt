Module: AI Answers & Analysis - YouTube Knowledge

Recommended environment
- A supported Python release with the official Google GenAI SDK (google-genai).
- Pydantic or equivalent validation for answer/citation/analysis output schemas.
- Versioned prompt templates and a Gemini-compatible context/token budget mechanism.
- An async client or worker boundary with provider timeouts and bounded retry handling.
- A reference dataset containing supported, unsupported, and cross-video questions.
- Pin a tested SDK version before implementation; do not copy legacy SDK imports blindly.

Required configuration
- GEMINI_API_KEY=: server-side credential for Gemini generation.
- LLM_MODEL=gemini-3.5-flash: the user's requested model identifier.
- LLM_TIMEOUT_SECONDS=60: timeout budget for a generation attempt.
- MAX_CONTEXT_TOKENS=24000: application input budget, not a claim about model capacity.
- ANSWER_MAX_OUTPUT_TOKENS=1200: application output limit.
- ENABLE_STREAMING=false: default to a final validated JSON response.
- RETRIEVAL_TOP_K=8: shared evidence retrieval setting.

Model compatibility note
- Google currently documents gemini-3.5-flash as deprecated and automatically routed to
  gemini-3.6-flash. Keep the model configurable and verify actual account access before use.
- Record the requested identifier and returned model/version metadata when available.
- Reference: https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash
- SDK reference: https://ai.google.dev/gemini-api/docs/libraries

Important requirements
- Answer from selected-video evidence and provide traceable citations.
- Say when evidence is insufficient; never invent quotes, timestamps, or sources.
- Model generation and 04's embedding model are separate configurations.
- These are planned requirements; no Gemini adapter or prompt pipeline is implemented yet.
