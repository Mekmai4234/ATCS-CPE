Module: Web App - YouTube Knowledge

Recommended environment
- Node.js with a supported LTS release, React/Next.js, and TypeScript.
- A CSS/component system for the video library, chat, and learning workspace.
- A query/cache library or a small typed API client for HTTP requests and job polling.
- A supported desktop/mobile browser and the YouTube embedded player interface.
- Frontend linting and a browser test runner when application source is added.
- Pin compatible runtime and package versions in manifests and lockfiles.

Required configuration
- NEXT_PUBLIC_API_BASE_URL=http://localhost:8000: the browser-accessible backend URL.
- WEB_ORIGIN=http://localhost:3000: the origin allowed by the backend.
- ENABLE_STREAMING=false: backend delivery mode; the frontend must use the same contract.
- .env.example is the planned shared configuration reference. A Next.js entrypoint must
  explicitly load the appropriate public values; a root .env is not automatically a frontend loader.

Important requirements
- Support importing YouTube URLs and display one card/status per video.
- Only ready videos can be selected as sources for AI answers.
- Keep GEMINI_API_KEY and embedding-provider credentials on the server.
- Render transcript text and model output safely; disable raw untrusted HTML.
- Keep navigation, forms, errors, and player controls accessible by keyboard.
- Use HTTPS for deployment; localhost HTTP is acceptable during development.
- This is a design specification. No frontend application or startup command exists yet.
