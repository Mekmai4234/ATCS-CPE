## Issues found and corrected during verification

receiver in real API mode. Fetch now uses a wrapper and the affected tests pass. Review of
the actual backend schema also corrected object-shaped artifact results and avoids duplicate
research artifact displays when both embedded artifacts and saved artifact IDs are returned.
Final test counts above refer to the corrected implementation.
