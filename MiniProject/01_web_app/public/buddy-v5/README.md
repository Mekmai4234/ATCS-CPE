# Approved Video Buddy artwork

19 transparent mascot poses and one login scene from the user's approved v5 design
review, exported as WebP for the real application. Each named file corresponds to
its page or state. The review sources are retained locally under
`MiniProject/output/design/video-buddy-review-v5/assets`.

Do not replace these with a single repeated pose. Page layout and readable text
belong in React/CSS; these assets are decorative, not screenshots of functional UI.
