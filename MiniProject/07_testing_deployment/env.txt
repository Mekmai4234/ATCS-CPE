Module 07: Verification environment

Python 3.11-3.13 and uv; install with uv sync --project 07_testing_deployment --locked.
The 07 pyproject.toml/uv.lock install modules 02-06 and pytest/Ruff.
Reports/caches belong under ignored 07/runtime. Pytest state uses a short OS temporary
root; select --temp-root or YK07_TEMP_ROOT when needed. The report records its location.
Offline suites need no credentials; live embedding tests are deselected.
Docker/Compose are required for container checks. Engine availability is checked separately.
The authorized repository-root .github/workflows/miniproject-offline.yml is the active CI.
Node 24, pnpm 11.25.0 and Playwright Chromium are needed for frontend checks.
Auth suites require the pending module 02 auth contract; use an isolated candidate while
it is unmerged. Fixture verifier injection exists only in tests/auth/conftest.py.
Public GOOGLE_CLIENT_ID/VITE_GOOGLE_CLIENT_ID are identifiers, not provider secrets.
Production requires AUTH_ENABLED=true, SESSION_COOKIE_SECURE=true, a registered HTTPS
WEB_ORIGIN, matching AUTH_TRUSTED_ORIGINS and reviewed integration evidence.
Never expose GEMINI_API_KEY, session cookies or Google credential tokens in web builds.

Deployment values are explicit in 07/compose.yaml: custom/live factory from 05,
Gemini embeddings, shared SQLite/Chroma volume, localhost API port 8007, separate worker.
Supply GEMINI_API_KEY securely only for live use. Validate account/model access separately.
Root .env.example still describes unsupported OpenAI embeddings. Do not mix fixture/live
state. 07 never edits application .env files. See README.md for actual commands.
