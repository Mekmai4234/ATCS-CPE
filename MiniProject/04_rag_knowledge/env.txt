Purpose
Build the searchable knowledge layer while preserving video and timestamp metadata.

Proposed environment
- Shared Python environment, ChromaDB, and an embedding-provider adapter.
- Persistent local storage for development; use a deployment-appropriate persistent service later.
- The original project proposes text-embedding-3-small; confirm availability and pin the selected configuration before integration.

Planned configuration
- OPENAI_API_KEY= (server-side only, if using this provider).
- EMBEDDING_MODEL=text-embedding-3-small
- CHROMA_PERSIST_DIR=./runtime/chroma
- CHUNK_TARGET_TOKENS=600
- CHUNK_OVERLAP_TOKENS=100
- RETRIEVAL_TOP_K=8
These are starting values for evaluation, not proven optimal settings.

Dependencies
03 provides transcript versions; 02 provides scope and persistence; 05 and 06 request evidence. Use the same embedding model for ingestion and querying.

Current status
No index, tokenizer selection, or retrieval implementation exists yet.
