Module: RAG Knowledge - Gemini-only live provider

Environment
- Python >=3.11,<3.14; uv.lock pins tested dependencies.
- google-genai async Gemini Developer API via explicit HTTPX transport.
- Chroma persistent vectors and SQLite publication tables in the existing 02 database.
- No OpenAI SDK, OpenAI credential or tiktoken dependency in module 04.
- Fixture hash embeddings support offline tests only; they are not a second live provider.
- Existing 02 schemas and execution contracts remain the integration boundary.

Configuration
- EMBEDDING_PROVIDER=gemini; EMBEDDING_MODEL=gemini-embedding-2.
- GEMINI_API_KEY=: server-side only, not committed or included in Docker images.
- EMBEDDING_DIMENSIONS=1536 (Gemini allows 128-3072).
- EMBEDDING_TOKENIZER=utf8-byte-budget-v1.
- CHUNK_TARGET_TOKENS=600; CHUNK_OVERLAP_TOKENS=100.
  Legacy names now specify offline UTF-8 byte budgets, NOT billable Gemini token counts.
- RETRIEVAL_TOP_K=8; EMBEDDING_BATCH_SIZE=16; RAG_OPERATION_TIMEOUT_SECONDS=60.
- CHROMA_PERSIST_DIR=./runtime/chroma, relative to MiniProject root.
- Precedence: environment > 04/.env > MiniProject/.env > defaults.
- Copy the module-local .env.example only if a local .env does not exist.

Boundaries
- Exact Gemini countTokens preflight includes retrieval formatting and enforces 8192 tokens.
- 02 alone owns retries, jobs and ready status; SDK retries are disabled.
- 05/06 generation uses its own LLM_MODEL, independent of the embedding model.
- Existing provider/configuration indexes require explicit reindex.
- No source files outside 04 were changed. Other modules/shared templates need team alignment.
- README.md contains startup/integration/Docker commands; TEST_REPORT.md records actual checks.
