### 04_rag_knowledge - Workflow Steps

A) Indexing Pipeline
--------------------
1. Receive normalized transcript segments and video/version metadata from 03.
2. Validate non-empty text, ordered intervals, stable IDs, and usable source metadata.
3. Group neighboring segments into chunks with configurable overlap.
4. Retain original segment references and calculate each chunk's time bounds.
5. Create an embedding for each chunk using EMBEDDING_MODEL.
6. Upsert vectors and metadata with stable IDs into the selected Chroma collection.
7. Publish the new indexed version only when all required chunks succeed.
8. Remove superseded version records after a successful replacement.
9. Report completion or a retryable/permanent failure to the backend job coordinator.

B) Question Retrieval Pipeline
------------------------------
1. Receive a question and validated source scope from 05 or an authorized tool in 06.
2. Embed the question using the same configuration as the target index.
3. Apply scope constraints, then retrieve ranked relevant chunks.
4. Select up to RETRIEVAL_TOP_K evidence records while limiting avoidable duplication.
5. Return chunk text and traceable video/timestamp metadata to the caller.
6. If no suitable evidence is available, return an empty/limited evidence result.

C) Complete-video Coverage Pipeline
-----------------------------------
1. Receive the explicit video scope for a full summary or comparison.
2. Enumerate all eligible chunks for each selected video, using pagination/batches.
3. Return chunk batches and coverage metadata to 05/06.
4. Report missing or partially indexed videos; do not label partial evidence as complete.
