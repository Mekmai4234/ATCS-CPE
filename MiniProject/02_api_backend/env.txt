Purpose
Provide the application API, persistence, and job coordination.

Proposed environment
- Python with a supported release, FastAPI, a database layer, and a migration tool.
- SQLite for the initial local prototype; reconsider PostgreSQL before multi-user deployment.
- A background worker consuming persisted jobs; use a durable queue service if deployment requires it.
- Pin actual dependencies and add startup commands when source code exists.

Planned configuration
- API_HOST=127.0.0.1
- API_PORT=8000
- WEB_ORIGIN=http://localhost:3000
- DATABASE_URL=sqlite:///./runtime/app.db
- JOB_MAX_ATTEMPTS=3
All relative runtime paths resolve from the MiniProject root.

Dependencies
