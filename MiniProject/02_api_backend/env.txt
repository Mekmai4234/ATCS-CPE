Module: API / Backend - YouTube Knowledge

Recommended environment
- A supported Python release with FastAPI, an ASGI server, and Pydantic validation.
- A database layer and migration tool; SQLite is the initial local-prototype option.
- A separately running worker that claims jobs from a persistent job store.
- An HTTP client for external adapters and a test runner for API/database integration.
- Use a deployment-appropriate database and durable queue when concurrency requires them.
- Pin tested dependency versions; implementation and startup commands are not present yet.

Required configuration
- API_HOST=127.0.0.1 and API_PORT=8000: local API binding.
- WEB_ORIGIN=http://localhost:3000: allowed frontend origin.
- DATABASE_URL=sqlite:///./runtime/app.db: application data connection.
- JOB_MAX_ATTEMPTS=3: bounded retries for retryable jobs.
- ENABLE_STREAMING=false: default to one validated JSON answer.
- All relative runtime paths resolve from the MiniProject root.

Important requirements
- Validate request bodies and authorized data scope before invoking a worker or model.
- Persist jobs before returning an accepted import response.
- Keep video import, chat, and research-run states distinct.
- Use parameterized queries/ORM bindings for database access.
- Persist conversation turns and citations durably; telemetry can be asynchronous.
- If multiple users are added, enforce ownership on application data and vector searches.
- Store credentials outside tracked files and use HTTPS in deployment.
